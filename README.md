# MNIST MLP Classifier Reimplement by PyTorch

## Overview

This project is re-implementation of MNIST MLP classifier with pyTorch.

## Setup and Run

### 1. Clone the Git Repo

```bash
git clone https://github.com/coderanger428/ai-mnist-mlp-pytorch.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run

```bash
python src/train.py

# OR

jupyter notebook experiment.ipynb

```
